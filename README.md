# CapiNews — Daily AI Intelligence

Relatório diário de inteligência em IA — EN · PT · ZH

Gerado automaticamente via Claude Code Routines às 12h (GMT-3).

## Frontend
https://skarL007.github.io/capinews-data

## Estrutura
- `index.html` — frontend CapiNews
- `data/latest.json` — relatório do dia (atualizado pela Routine)
- `data/YYYY-MM-DD.json` — arquivo histórico por data
- `data/index.json` — índice de datas disponíveis
